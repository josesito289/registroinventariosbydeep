# Registro de Inventarios — PWA

Aplicación web progresiva (PWA) para registrar inventarios físicos de productos,
con exportación de reportes en **JSON / CSV / TXT** para consumo posterior desde
una aplicación de Windows.

- Repositorio: `registroinventariosbydeep`
- Versión actual: **1.0.0**
- Instalable en Android (Chrome) como app "nativa" (standalone)
- Funciona offline después de la primera carga
